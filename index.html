Welcome to vi·si·cal·i·ty


A web-based music visualizer powered by Web Audio API and D3.js.


Features:


  • Upload local audio files or use the built-in demo song.
  • 9 visualizer designs & 9 color schemes.
  • Customizable background gradient colors.
  • Adjustable gain (volume) control.
  • YouTube video embed panel.
  • Fullscreen mode support.
  • Keyboard shortcut controls.
  • Auto-hides UI when audio is playing.

Originally designed & developed by Derek Wolpert.


Modernized by ArndOZ — Modern UI, responsive mobile layout & YouTube player integration.
